# Phase gate review

1. Open `docs/plan/IMPLEMENTATION_PLAN.md` and find the acceptance list for the gate.
2. For every item give: status (met / partly met / not met), an evidence link (test report, probe report, exported PDF, metrics table) and a one-line note.
   Never mark an item met without evidence.
3. Add:
   - metrics against targets;
   - the top five open risks, each with an owner;
   - decisions needed, each with a date;
   - proposed scope changes for the next phase.
4. Write `docs/gates/G<n>_<yyyy-mm-dd>.md`, at most two pages.
